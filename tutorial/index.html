Chrome Extension Starter

Vite • Svelte 5 • TypeScript • Tailwind (optional)

Quick Start 
npm run new:content hello
npm run build
npm run preview
Entries
  • src/content/*.ts: separate content scripts. Configure in scripts/config/content.json.
  • src/background/index.ts: background service worker (optional).
  • src/popup/index.html: popup (optional).
  • src/options/index.html: options page (optional).
  • src/sidepanel/index.html: side panel (optional).
Manifest

The template at public/manifest.json is the source of truth. The build step merges new entries without overwriting existing fields.

Commands 
npm run new:content <name>
npm run build:prepare
npm run build
npm run preview

You can customize matches and timing per content script in scripts/config/content.json. Existing manifest fields are never overwritten by the generator.
